# Requirements — Planning Poker

## 概要

アジャイル開発チームがオンラインでストーリーポイントの見積もりを行うための
リアルタイム同期型プランニングポーカーアプリ。

---

## ユーザーストーリー

### US-01 ルーム作成
- **As** ファシリテーター
- **I want** ルーム名を入力して新しいセッションを作成できる
- **So that** チームメンバーを招待して見積もりを始められる

**受け入れ条件**
- [ ] ルーム名（最大50文字）を入力してルームを作成できる
- [ ] 作成後、ルームURLへ自動でリダイレクトされる
- [ ] 作成者はそのセッション内で「ファシリテーター権限」を持つ
- [ ] 作成者の権限はブラウザの sessionStorage で管理される（再読み込み後も維持）

---

### US-02 ルーム参加
- **As** 開発メンバー
- **I want** ルームのURLまたはIDを使って参加できる
- **So that** チームのセッションに簡単に合流できる

**受け入れ条件**
- [ ] ルームIDを入力してトップページから参加できる
- [ ] 共有されたURLに直接アクセスして参加できる
- [ ] 参加時に表示名（最大20文字）の入力が必要
- [ ] 存在しないルームIDを入力した場合、エラーメッセージを表示する
- [ ] ページを再読み込みしても参加状態が維持される（sessionStorage）

---

### US-03 カード投票
- **As** 開発メンバー
- **I want** フィボナッチ数列のカードから1枚選んで投票できる
- **So that** 自分の見積もりをチームに伝えられる

**受け入れ条件**
- [ ] 使用カード: `1, 2, 3, 5, 8, 13, 21, ?, ☕`
- [ ] 選択済みのカードを再度押すと投票を取り消せる
- [ ] 投票はカードがオープンされるまで他の参加者に見えない（裏向き表示）
- [ ] 投票済みの場合、カードに ✓ マークを表示
- [ ] 未投票の場合 `…` を表示
- [ ] カードがオープン済みの場合、選択・変更はできない

---

### US-04 リアルタイム同期
- **As** 全参加者
- **I want** 他の参加者の操作（参加・投票・オープン・リセット）が即座に反映される
- **So that** ページを手動でリロードせずにセッションを進行できる

**受け入れ条件**
- [ ] 新しいメンバーが参加したら全員の画面に即座に表示される
- [ ] 誰かが投票・取り消しをしたら投票状況が即座に更新される
- [ ] カードオープン時、全員の画面で同時に投票値が公開される
- [ ] リセット時、全員の画面で投票がクリアされ伏せ状態に戻る
- [ ] Supabase Realtime (PostgreSQL CDC) を使用して実現する

---

### US-05 カードオープン
- **As** ファシリテーター
- **I want** 全員が投票したタイミングでカードを一斉にオープンできる
- **So that** 偏りのない見積もり結果を確認できる

**受け入れ条件**
- [ ] オープンボタンはファシリテーター（ルーム作成者）にのみ表示される
- [ ] 全員が投票済みのときのみオープンボタンが有効になる
- [ ] 未投票者がいる場合、ボタンはグレーアウトしてクリック不可
- [ ] オープン後、全員のカード値が一斉に公開される
- [ ] オープン後は参加者のカード選択が無効になる

---

### US-06 結果表示
- **As** 全参加者
- **I want** オープン後に集計結果（最頻値・平均）を確認できる
- **So that** チームで合意形成の議論をスムーズに始められる

**受け入れ条件**
- [ ] 最頻値と平均を2カラムで並べて表示する
- [ ] `?` と `☕` は数値集計の対象外とする
- [ ] 数値票がゼロの場合（全員 ? か ☕）は `-` を表示する

---

### US-07 次のラウンド（リセット）
- **As** ファシリテーター
- **I want** カードをリセットして次のチケットの見積もりを始められる
- **So that** 連続してプランニングポーカーを進行できる

**受け入れ条件**
- [ ] リセットボタンはファシリテーターにのみ表示される
- [ ] リセット後、全員の投票がクリアされ伏せ状態に戻る
- [ ] 参加者一覧はリセット後も維持される（退室しない）

---

### US-08 招待共有
- **As** ファシリテーター
- **I want** URLまたはルームIDをワンクリックでコピーできる
- **So that** メンバーを手軽に招待できる

**受け入れ条件**
- [ ] 「招待URL」ボタンで現在のURLをクリップボードにコピーできる
- [ ] ルームID横の📋ボタンでルームIDをコピーできる
- [ ] コピー成功時、画面下部にトースト通知を表示する
- [ ] トースト通知は2.2秒後に自動で消える

---

## 非機能要件

| カテゴリ | 要件 |
|---|---|
| リアルタイム性 | 操作から反映まで 1秒以内（通常ネットワーク環境） |
| 対応ブラウザ | Chrome / Safari / Firefox / Edge 最新版 |
| レスポンシブ | スマートフォン（375px〜）〜デスクトップ（1280px）対応 |
| 認証 | 不要（名前入力のみ、匿名参加） |
| データ永続性 | セッション内のみ（ルームは作り捨て運用を想定） |
| アクセシビリティ | aria-pressed・aria-live・role="status" 対応 |

---

## 制約・前提

- インフラ: AWS Amplify Hosting（フロントエンド） + Supabase（DB / Realtime）
- フレームワーク: Next.js 16 (App Router) + Tailwind CSS v4
- カード値はフィボナッチ固定（カスタマイズ不要）
- ファシリテーター権限は sessionStorage ベース（マルチデバイス引き継ぎ不要）
