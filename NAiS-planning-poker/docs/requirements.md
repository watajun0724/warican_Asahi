# NAiS Planning Poker - 要件定義書

## 概要

アジャイル開発チームが使用するリアルタイムプランニングポーカーアプリケーション。  
複数人が同時にアクセスし、ストーリーポイントの見積もりをリアルタイムで行える。

## 技術スタック

| カテゴリ | 技術 |
|----------|------|
| フロントエンド | Next.js 14 (App Router) + TypeScript |
| スタイリング | Tailwind CSS |
| バックエンド/DB | Supabase (PostgreSQL + Realtime) |
| ホスティング | AWS Amplify Hosting |
| テスト | Vitest + Testing Library |

## ユーザーストーリー

### Epic 1: ルーム管理

| ID | As a... | I want to... | So that... | 優先度 |
|----|---------|-------------|------------|--------|
| US-01 | ファシリテーター | ルームを作成したい | チームを招待できる | Must |
| US-02 | 参加者 | URL でルームに参加したい | セットアップ不要で参加できる | Must |
| US-03 | 参加者 | 名前を入力して参加したい | 誰が投票したか分かる | Must |
| US-04 | ファシリテーター | ルームのトピック（ストーリー名）を設定したい | 何の見積もりか分かる | Should |

### Epic 2: 投票

| ID | As a... | I want to... | So that... | 優先度 |
|----|---------|-------------|------------|--------|
| US-05 | 参加者 | カードを選択したい | 見積もりを投票できる | Must |
| US-06 | 参加者 | 投票を変更したい | 選び直しができる | Should |
| US-07 | 全員 | 誰が投票済みか分かりたい（カード枚数表示） | 状況をリアルタイムに把握できる | Must |
| US-08 | 全員 | 投票中は他の人のカード値は見えないようにしたい | バイアスなく投票できる | Must |

### Epic 3: 結果公開

| ID | As a... | I want to... | So that... | 優先度 |
|----|---------|-------------|------------|--------|
| US-09 | ファシリテーター | 全カードを一斉公開したい | 合意形成を進められる | Must |
| US-10 | 全員 | 公開後に全員の投票値を見たい | 差異を確認できる | Must |
| US-11 | 全員 | 平均・最頻値・最大・最小を見たい | 合意点を素早く把握できる | Should |

### Epic 4: ラウンド管理

| ID | As a... | I want to... | So that... | 優先度 |
|----|---------|-------------|------------|--------|
| US-12 | ファシリテーター | 次のラウンドをリセットしたい | 次のストーリーに進める | Must |
| US-13 | 参加者 | 退出できたい | ルームを離れられる | Should |

## カード定義

```
1, 2, 3, 5, 8, 13, 21, ?, ☕
```

- `?` = わからない / 情報不足
- `☕` = 休憩が必要

---

## 非機能要件

| カテゴリ | 要件 |
|----------|------|
| リアルタイム性 | 投票・公開操作は 1 秒以内に全員に反映 |
| 同時接続 | 1 ルーム最大 20 人 |
| ルーム有効期限 | 24 時間（自動削除） |
| モバイル対応 | スマートフォンでも操作可能なレスポンシブ UI |
| アクセシビリティ | WCAG 2.1 AA 準拠を目標 |

## 受け入れ条件

### US-01: ルーム作成
- [ ] ルーム名を入力してルームを作成できる
- [ ] 作成後、`/room/[roomId]` にリダイレクトされる
- [ ] ルーム URL をクリップボードにコピーできる
- [ ] 作成者がファシリテーターとして設定される

### US-05: カード選択
- [ ] 9 種類のカードが表示される
- [ ] 選択したカードがハイライトされる
- [ ] 選択変更が可能（再クリックで変更）
- [ ] 全員の投票状況（済み/未）がリアルタイムで更新される

### US-09: カード公開
- [ ] ファシリテーターのみ「公開」ボタンを押せる
- [ ] 公開後、全員のカード値が一斉に表示される
- [ ] 平均・最頻値・最大・最小が表示される

### US-12: リセット
- [ ] ファシリテーターのみ「次のラウンド」ボタンを押せる
- [ ] リセット後、全員の投票がクリアされる
- [ ] リセット後、カードが非公開状態に戻る
