# NAiS Planning Poker - UI設計書

## 画面構成

```
/                     → ホーム画面（ルーム作成）
/room/[roomId]        → ポーカーメイン画面
```

---

## コンポーネントツリー

```
app/
├── page.tsx                    # ホーム画面
│   └── CreateRoomForm          # ルーム作成フォーム
│
└── room/[roomId]/
    └── page.tsx                # ルームページ（参加者名入力 or ポーカー画面）
        ├── JoinForm            # 名前入力フォーム（未参加時）
        └── PokerRoom           # メインのポーカー画面
            ├── RoomHeader      # ルーム名・トピック・URL コピー
            ├── ParticipantList # 参加者一覧（投票状況付き）
            │   └── ParticipantCard  # 個別参加者カード
            ├── CardDeck        # カード選択エリア
            │   └── PokerCard   # 個別カード
            ├── ResultPanel     # 公開後の結果表示（統計）
            └── ActionBar       # 公開・リセットボタン（ファシリテーターのみ）
```

## カラーパレット

| 用途 | カラー |
|------|--------|
| Primary | Indigo-600 (#4F46E5) |
| Accent | Violet-500 (#8B5CF6) |
| Success | Emerald-500 (#10B981) |
| Warning | Amber-400 (#FBBF24) |
| Background | Slate-900 (#0F172A) |
| Surface | Slate-800 (#1E293B) |
| Text | Slate-100 (#F1F5F9) |

ダークテーマをベースとし、プロフェッショナルかつゲーム的な雰囲気を演出。

## コンポーネント仕様

### PokerCard

| 状態 | 見た目 |
|------|--------|
| 未選択 | ボーダー白、背景グレー |
| ホバー | ボーダー indigo、少し拡大 |
| 選択済み | 背景 indigo、白文字、拡大 |
| 公開後（他者） | 背景 violet、白文字 |
| 非活性（公開後） | opacity-50 |

### ParticipantCard

| 状態 | 見た目 |
|------|--------|
| 未投票 | グレー背景、点線ボーダー |
| 投票済み | 緑背景、✓ アイコン（値は非表示） |
| 公開後 | カード値を大きく表示 |
| オフライン | opacity-40 |
